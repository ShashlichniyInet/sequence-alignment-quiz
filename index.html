У TTAC и ACGG общий участок AC лежит на концах. У TTACGG и CCACAA тот же участок лежит внутри обеих последовательностей. Локальный алгоритм может выбрать его целиком, а overlap из лекции требует прохода от одной границы матрицы до другой.

Скоринг парного выравнивания

В простой схеме совпадение даёт +1, замена −1, символ напротив гэпа −2. Общий балл равен сумме вкладов.

 A  C  -  G  T
 A  T  C  G  -
+1 −1 −2 +1 −2 = −3
  • Линейный штраф за гэп длины k равен −kd. При d = 2 три дефиса стоят −6 независимо от расположения.
  • Аффинный штраф равен −d − (k − 1)e. Первый дефис оплачивается открытием, остальные продлением. При открытии 5 и продлении 1 один блок из трёх дефисов даёт −7, три отдельных гэпа дают −15.
  • Матрица идентичности различает совпадение и замену. BLOSUM задаёт отдельную оценку для каждой пары аминокислот. Некоторые замены получают положительный балл. Статья о BLOSUM

Идентичность — доля точных совпадений с указанным знаменателем. В отчёте на слайде 12 Identities = 33/137, а Positives = 55/137. Второй показатель включает также замены с положительным баллом.

Динамическое программирование

Пусть x идёт по строкам, y — по столбцам. При глобальном выравнивании F[i,j] — лучший балл выравнивания их префиксов длины i и j. Для каждой клетки сравни три варианта последнего столбца. g — отрицательный линейный штраф.

ПереходСтолбецБаллы
Диагональ ↖xᵢ / yⱼF[i−1,j−1] + s(xᵢ,yⱼ)
Сверху ↑xᵢ / −F[i−1,j] + g
Слева ←− / yⱼF[i,j−1] + g

Берём максимум. При фиксированном последнем столбце оптимальный ответ использует оптимальное решение предыдущей подзадачи. Без этого её можно было бы заменить и улучшить ответ. Таблица хранит ответы для повторного использования. Время заполнения и память полной таблицы — O(nm).

РежимКрая и переходыОбратный проход
ГлобальныйПервая строка и столбец 0, g, 2g, …. Три перехода.Из нижнего правого угла до (0,0).
ЛокальныйНа краях нули. В максимум включаем ещё 0.Из максимума всей матрицы до первой клетки с нулём.
OverlapНа краях нули. Три перехода.Из максимума на последней строке или столбце до верхней или левой границы.

Чтобы целиком уложить короткую x в длинную y, обнули первую строку, оставь штрафы в первом столбце и бери максимум последней строки. Это освобождает префикс и суффикс длинной последовательности.

Глобальное выравнивание AG и ACG

       ∅   A   C   G
  ∅    0  -2  -4  -6
  A   -2   1  -1  -3
  G   -4  -1   0   0

В нижней правой клетке кандидаты: −1+1=0 по диагонали, −3−2=−5 сверху, 0−2=−2 слева. Обратный путь ↖ ← ↖ даёт столбцы G/G, −/C, A/A. Читаем их с конца и получаем A-G / ACG, балл 0. Равные максимумы могут давать несколько оптимальных путей.

Эволюция глобинов

Предковый глобин → дупликации и расхождение копий → ветви миоглобинов и гемоглобинов → разделение гемоглобиновой линии на α- и β-подобные глобины. Позднейшие дупликации дали гены, активные на разных стадиях развития. Основной взрослый гемоглобин человека HbA — α₂β₂, фетальный HbF — α₂γ₂. Исследование α- и β-глобинов

  • Гомологи имеют общее происхождение. Паралоги разошлись после дупликации, как α- и β-глобины. Ортологи разошлись при разделении видов.
  • Миоглобин связывает кислород в мышцах и обычно работает как мономер. HbA переносит кислород в крови, состоит из четырёх цепей и связывает кислород кооперативно.
  • В лекционном примере у миоглобина и гемоглобина 24% идентичности в показанном выравнивании. Глобиновая укладка при этом может сохраняться. Вставки и делеции в петлях иногда совместимы с сохранением общей структуры. Исследование эволюции семейства глобинов

Множественное выравнивание и сумма пар

В каждом столбце возьми все неупорядоченные пары строк. Для k строк это k(k−1)/2 пар на столбец. Сложи оценки по всем столбцам. В примере пара -/- даёт 0.

1  A C - G
2  A - T G
3  A C - -
СтолбецПары 1–2, 1–3, 2–3Сумма
A A A+1, +1, +1+3
C - C−2, +1, −2−3
- T -−2, 0, −2−4
G G -+1, −2, −2−3

Итого −7. Можно считать и по парам строк, сохраняя столбцы готового выравнивания. Если для каждой пары задан аффинный штраф, сначала удали из её проекции столбцы -/-, затем посчитай открытия и продления блоков гэпов.

Что запомнить из семинара

  • CytBProt и две матрицы. Сравнивай положение гэпов и консервативные блоки при BLOSUM и матрице идентичности. Для полноразмерных близких гомологов сходной длины очень длинные гэпы обычно не ожидаются.
  • CytBProt и CytBDNA. Синонимичные замены меняют ДНК, сохраняя аминокислоту. Внутренний гэп длины, не кратной трём, в выравнивании целых кодирующих последовательностей стоит проверить на артефакт или сдвиг рамки.
  • Arabidopsis и гексокиназы. Сохранение участка у растения и позвоночных позволяет предположить функциональное или структурное ограничение. Если гексокиназа 1 человека ближе к гексокиназе 1 собаки, чем к гексокиназе 2 человека, это согласуется с дупликацией до разделения видов. Для сравнения скоростей эволюции нужны сопоставимые ветви, единицы и модель расстояния.

Пробный квиз

Дай себе 15 минут. Раскрывай ответ после решения.

  1. Выбери тип для двух полноразмерных ортологов, общего внутреннего домена, перекрывающихся концов прочтений и короткой последовательности, целиком вложенной в длинную.
    Ответ

    Глобальное, локальное, перекрывающееся и полуглобальное соответственно.

  2. Посчитай балл AC-GT / A-CGT при +1 / −1 / −2.
    Ответ

    +1−2−2+1+1 = −1.

  3. При открытии 5 и продлении 1 оцени один блок гэпа длины 4 и два блока длины 2.
    Ответ

    Один блок: −5−3 = −8. Два блока: 2×(−5−1) = −12.

  4. Заполни локальную матрицу для TAC по строкам и GAC по столбцам при +1 / −1 / −2. Восстанови выравнивание.
    Ответ

    AC / AC, балл 2. Два диагональных шага из (3,3) до нуля в (1,1).

           ∅  G  A  C
  ∅    0  0  0  0
  T    0  0  0  0
  A    0  0  1  0
  C    0  0  0  2
  5. Найди лучшее перекрытие TTAC по строкам и ACGG по столбцам при той же схеме. Укажи координаты начала и конца.
    Ответ

    AC / AC, балл 2. От (2,0) до (4,2) двумя диагоналями. Префикс TT первой последовательности и суффикс GG второй свободны.

  6. Объясни вслух, как появились α- и β-глобины, чем различаются HbA и HbF и почему структура может сохраняться при низкой идентичности.
    Ответ

    Дупликация предкового гена и расхождение копий. HbA — α₂β₂, HbF — α₂γ₂. Часть замен и вставок, например в петлях, совместима с сохранением глобиновой укладки.

  7. Найди сумму пар при +1 / −1 / −2 и -/- = 0. 
    AC-G
A-TG
AC--
AT-G
    Ответ

    Шесть пар на столбец. Вклады +6, −7, −6, −3, результат −10. В C - C T одна пара C/C, две C/T и три пары с гэпом.
